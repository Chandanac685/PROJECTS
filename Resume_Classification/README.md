# NLP-based Resume Classification System

## Project Overview

This project automatically classifies resumes into different job categories using Natural Language Processing (NLP) and Machine Learning.

## Objectives

- Automate resume screening
- Reduce manual HR effort
- Improve recruitment efficiency

## Workflow

- Text Preprocessing
- Tokenization
- Stop-word Removal
- TF-IDF Vectorization
- Model Training
- Model Evaluation
- Streamlit Deployment

## Models Used

- SVM
- Random Forest
- Logistic Regression
- Naive Bayes
- XGBoost

## Evaluation Metrics

- Accuracy
- Precision
- Recall
- F1-score

## Technologies

- Python
- Scikit-learn
- Pandas
- Streamlit
- Joblib

## Features

- Resume Upload
- Resume Classification
- Skill Extraction
- Candidate Ranking
- HR Dashboard

## Future Improvements

- BERT-based Resume Classification
- PDF Parsing Improvements
- Cloud Deployment
