# Bankruptcy Prediction using Machine Learning

🚀 **Live Demo:** [Bankruptcy Prediction App](https://chandana-bankruptcy-prevention-app.streamlit.app/)

## Project Overview

This project predicts whether a company is likely to face bankruptcy using Machine Learning techniques.

## Objectives

- Predict bankruptcy risk
- Support financial decision-making
- Improve risk assessment

## Workflow

- Data Cleaning
- Feature Engineering
- Exploratory Data Analysis
- Model Training
- Model Evaluation
- Streamlit Deployment

## Algorithm Used

- Random Forest

## Evaluation Metrics

- Accuracy
- Precision
- Recall
- F1-score
- ROC-AUC

- Streamlit
