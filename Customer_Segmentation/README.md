# Customer Segmentation using K-Means Clustering

🚀 **Live Demo:** [Customer Segmentation App](https://chandana-customer-segmentation-app.streamlit.app/)

## Project Overview

This project analyzes customer purchasing behavior and segments customers into meaningful groups using K-Means Clustering.

## Objectives

- Analyze customer behavior
- Identify customer groups
- Support targeted marketing strategies

## Workflow

- Data Cleaning
- Exploratory Data Analysis (EDA)
- Feature Engineering
- Label Encoding
- StandardScaler
- PCA
- K-Means Clustering
- Cluster Evaluation

## Algorithms Used

- K-Means

## Evaluation Metrics

- Silhouette Score
- Davies-Bouldin Index
- Calinski-Harabasz Score

## Technologies

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn

## Results

Successfully segmented customers into meaningful groups that can support business decision-making and targeted marketing.

- Interactive Dashboard
